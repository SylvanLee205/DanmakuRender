运行单元测试需要额外的测试依赖

【上游 requirements.txt 遗漏的测试依赖】
  psutil
    用于 unit_tests/test_downloader_memory.py（内存回归测试）。
    不装的话该文件整个被 unittest 跳过（其余 410 个用例仍可跑）。

    安装：.\.venv\Scripts\python.exe -m pip install psutil

  注：这只是**测试依赖**，DMR 运行时不需要 psutil。

【如何跑测试】
  cd F:\DanmakuRender_AutoUp
  .\.venv\Scripts\python.exe -m unittest discover -s unit_tests -t . -v

  预期结果：Ran 437 tests, OK (expected failures=5)
  实测耗时：约 43 秒

【已有的测试套件来源】
  来自上游提交 ab8d3f3「录制状态持久化与可靠恢复」，共 20 个文件 / 437 用例。
  详见 docs/上游合并与部署记录-20261015.md
