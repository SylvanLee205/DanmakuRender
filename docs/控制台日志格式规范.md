# 控制台日志格式规范（2026-10-07 定义）

**目标**：控制台只显示"发生了什么事"的基本信息，**不带长路径**、**不重复**、**不显示技术细节**。

---

## 二、"说两遍"的根因（已修）

用户看到的那条重复消息：

```
[07:24:07][info]: 苏苏没烦恼: 视频 ['./直播回放/...07点12分（弹幕版）.mp4'] 上传完成: File ./直播回放/...07点12分（弹幕版）.mp4 upload success..
```

**它不是被打印两次，而是消息本身就含两遍路径。**

链路：
```
DMR/Uploader/subprocess_uploader.py L174
    message += f'File {file.path} upload success.\n'          <- 第一遍路径
        ↓ 作为 desc 上传
DMR/Uploader/__init__.py L177
    msg = f"视频 {[f.path for f in task['files']]} 上传完成: {desc}"   <- 第二遍路径
        ↓ 作为管道事件
DMR/Task/liveevents.py onUploadEnd L620
    self.logger.info(f'{self.name}: {message.msg}.')          <- 原样打印
```

**修复**：把 `Uploader/__init__.py` 里构造的 msg 改成只带文件名，
不再拼接 `desc`。这样事件描述短了，插件那边打印也短了。

## 三、改动清单

| 文件 | 改动 |
|---|---|
| `DMR/Render/__init__.py` | 渲染完成 msg 只留文件名；`正在渲染` 用 basename；import 加 `basename` |
| `DMR/Render/dmrender.py` | GOP 日志 `info` → `debug` |
| `DMR/Cleaner/__init__.py` | `正在清理原文件:`/`正在清理弹幕文件:` 用 basename；清理完成事件去掉 method 和完整列表 |
| `DMR/Uploader/__init__.py` | `正在上传:`/上传完成事件/重传警告 都用 basename；import 加 `basename` |
| `DMR/Downloader/stream_downloader.py` | 分段录制完成用 basename；import 加 `basename` |
| `main.py` | 新增 `--quiet` 参数 + 启动横幅 |
| `Start_Render.bat` | 加 `--quiet`；通知 curl 加 `-m 15` 超时 |

## 四、两级输出策略

```
控制台 (--quiet, WARNING+)     日志文件 (DEBUG)
  ├─ 警告/错误                   ├─ 全部 DEBUG，含 GOP、engine 消息字典等
  └─ 启动横幅                    └─ 出问题看这里
```

**为什么能放心降噪**：日志文件**永远保留全量 DEBUG**，不受 `--quiet` 影响。
所以控制台可以只留关键信息，排查时去看 `logs/DMR-日期.log`。

## 五、还有一个"重复"不是 bug

用户举例里 `苏苏没烦恼: 直播开始` 出现了两次：

```
[06:12:25] 苏苏没烦恼: 直播开始
[07:24:18] 苏苏没烦恼: 直播开始     <- 相隔 72 分钟
```

那是**两次不同的开播**（中间断流过），不是重复打印。

# 附：服务版 HTTPS 已启用（2026-10-07）

```toml
# C:\Windows\System32\config\systemprofile\Waytech\CloudDrive2\config.toml
[webconfig]
http_port     = 19798
https_port    = 19799
enable_https  = true      # 原来是 false
cert_file     = '...\certs\server.crt'
key_file      = '...\certs\server.key'
```

**验证结果**：
```
http://127.0.0.1:19798/     -> HTTP 200  ✅
https://127.0.0.1:19799/    -> HTTP 200  ✅
https://100.75.58.27:19799/ -> HTTP 200  ✅  <- 手机/远程用这个
http://.../dav              -> HTTP 401（需认证）✅
https://.../dav             -> HTTP 401（需认证）✅
rclone（走 127.0.0.1:19798）-> exit=0，不受影响 ✅
```

**证书**：自签名，2026-10-01 生成，**2027-10-01 到期**。
浏览器会警告"不受信任"，点"继续访问"即可。
想消除警告需要受信任证书（Tailscale 可以签发，属另一件事）。

**好处**：
1. Tailscale 段是 WireGuard 加密的，但**手机→CD2 这一段原来是明文 HTTP**，现在也加密了
2. 浏览器不再标记"不安全"，部分浏览器 API 要求安全上下文
3. 登录密码不会明文过网

**回滚**：把 `enable_https` 改回 `false` 并重启服务。备份在
`config.toml.bak-20261007-140132`。
