控制台日志降噪（--quiet）+ 记录服务版优势与远程访问安全

【用户反馈】"终端的输出有点乱，信息也有点多，看不过来"

【根因】main.py 里控制台 handler 固定 INFO 级别：
    logger.setLevel(logging.DEBUG)          # 总开关
    console_handler.setLevel(logging.INFO)  # 控制台
    file_handler.setLevel(logging.DEBUG)    # 日志文件
每个分段都打一遍"渲染完成/正在上传/正在清理/清理完成/上传完成"+GOP+分段完成，
累积起来就很多。

【改动 1】main.py 新增 --quiet 参数
  parser.add_argument('--quiet', nargs='?', const='quiet', default=None,
                      metavar='LEVEL', ...)
  级别映射:
    不带 --quiet     -> INFO（原行为）
    --quiet         -> WARNING（只留警告和错误）
    --quiet=error   -> ERROR
    --quiet=debug   -> DEBUG（排查用）
    乱填            -> WARNING（回退）
  **关键保证：日志文件永远是 DEBUG，不受 --quiet 影响。**
  所以降噪不会丢失排查能力，出问题看 logs/DMR-日期.log 即可。

【改动 2】main.py 加启动横幅（用 print 直出，任何级别都显示）
  因为静默后控制台没 INFO 日志，很容易看不出程序还在跑。
  ====================================================================
    DanmakuRender-5 x.x.x   已启动
    控制台输出级别: WARNING(安静)
    完整日志(DEBUG): logs/DMR-20261007.log
    （控制台已静默，只显示警告/错误；想恢复详细输出去掉 --quiet）
  ====================================================================

【改动 3】Start_Render.bat 加 --quiet
  ".\.venv\Scripts\python.exe" main.py --quiet
  备份: Start_Render.bat.bak-20261007-134708
  ⚠️ 该文件是 UTF-8 无 BOM，改的时候必须显式指定编码，
     用 PowerShell 的 Get-Content/Set-Content 会把中文变乱码。

【说明：用户说的"有些甚至说两次"不是重复日志】
  [06:12:25] 苏苏没烦恼: 直播开始
  [07:24:18] 苏苏没烦恼: 直播开始     <- 相隔 72 分钟
  那是两次不同的开播（中间断流过）。真正啰嗦的是每个分段的固定句式。

【用户发现的服务版优势（应用版没有的）】
1. 稳定性明显更好
2. **可以用 Tailscale IP 远程访问网页**：http://100.75.58.27:19798/
   应用版做不到（推测：服务版监听 0.0.0.0，应用版可能只绑 127.0.0.1；
   或防火墙规则按程序授权时，SYSTEM 服务比用户会话程序更容易通过）
3. 挂载本地盘效果好
4. 不弹控制台窗口（Session 0）

【⚠️ 远程访问安全发现（重要）】
服务版监听 0.0.0.0:19798，实测三个地址都能打开 Web 管理界面，
**且不需要登录**：
  http://127.0.0.1:19798/     -> HTTP 200
  http://100.75.58.27:19798/  -> HTTP 200   <- Tailscale
  http://192.168.5.5:19798/   -> HTTP 200   <- 局域网

但 WebDAV 是安全的：
  webdav_config.json: clouddrive_account_enabled=true,
                      anonymous_access_enabled=false
  /dav 路径需要账户认证（实测 HTTP 401）

管理界面实际权限：探测常见 API 路径全部 404，但界面引用的 JS 里有
remote-upload-helpers.js / qr-code-helpers.js，说明界面确实有操作功能。
API 路径没猜到不等于没有。

建议：
  ✅ Tailscale 远程访问没问题（加密私有网络）
  ❌ 绝对不要给 19798 做公网端口转发
  🟠 局域网设备杂的话，可用防火墙限制 19798 只允许 100.64.0.0/10
     （Tailscale 网段）。rclone 走 127.0.0.1 不受影响
