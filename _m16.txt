修三个问题：终端像卡死、HTTPS 手机无反应、清理消息合并

【问题1：重启后终端像卡死，没有任何输出】
诊断：DMR **完全正常** —— PID 4324，CPU 7.5 秒，Responding=True，
启动于 14:01:58。只是那 10 分钟没有事件。

真正原因：我上一轮把 --quiet 设成 WARNING 级别，
**连"直播开始"这种基本消息都不显示了**，所以看起来像卡死。
这是我的设计失误 —— 你要的是"信息少但不至于空白"。

修法：引入自定义级别 PROGRESS = 25（介于 INFO=20 和 WARNING=30 之间）
  main.py:  PROGRESS = 25; logging.addLevelName(PROGRESS, 'PROGRESS')
  --quiet 不带值 -> PROGRESS（原来是 WARNING）
  各级别：
    --quiet=info     INFO      详细（原行为）
    --quiet          PROGRESS  关键进度 + 警告错误 ★默认
    --quiet=warning  WARNING   只有警告错误
    --quiet=error    ERROR     只有错误
    --quiet=debug    DEBUG     很吵

  标记为 PROGRESS 的关键进度（这些在 --quiet 下会显示）：
    DMR/Task/liveevents.py     defaultEvent（直播开始/结束等）
                               onLiveSegment（分段录制完成）
                               onRenderEnd（渲染完成）
                               onUploadEnd（上传完成）
    DMR/Render/__init__.py     正在渲染
    DMR/Uploader/__init__.py   正在上传
    DMR/Cleaner/__init__.py    正在清理原文件

  保持 INFO（--quiet 下不显示，避免刷屏）：
    liveevents.py onLiveEnd 的"xxx: 直播已结束"（30 个任务轮流刷）
    engine 的消息字典（debug）
    GOP（debug）

【问题2：HTTPS 19799 手机没反应】
诊断：本机实测 HTTPS **完全正常** —— HTTP 200、TLSv1.3、AES256-GCM。
      19799 监听 0.0.0.0 + ::，从 Tailscale IP 也能拿到 200。
但证书是**自签名**的，rclone 不跳过校验时直接报：
    x509: certificate signed by unknown authority
手机浏览器遇到不受信任证书会**静默拦截**（Android Chrome 尤其明显），
所以表现为"没反应"。

这是自签名证书的固有限制，不是配置错误。
查了一下 Tailscale 域名是 win-e462mto1sb0.tail506a91.ts.net，
但 CertDomains 为空 —— 没申请 Tailscale 的受信任证书。

处置：**回滚到 HTTP**，恢复你手机本来能用的状态
  config.toml: enable_https true -> false
  19799 监听归 0，19798 正常
真要 HTTPS 且无警告，应走 Tailscale 证书（信任链是 Let's Encrypt），
那是另一件事，需要开 MagicDNS + 在 Tailscale 后台申请证书。

【问题3：WebDAV 不太行】
实测都正常：
  HTTP  127.0.0.1:19798/dav  -> 401（需认证）✅
  HTTPS 127.0.0.1:19799/dav  -> rclone --no-check-certificate 读到 16 项 ✅
  HTTP  rclone 读云端         -> 16 个目录 ✅

所以 WebDAV 服务端没问题，手机端失败大概率是证书警告或端口用错。
