重启通知改为动态生成并由 DMR 在启动成功后发送（内容丰富化）

【用户需求】
"我想让那个重启通知消息再丰富一些，标题是 DanmakuRender状态报告？
 内容是：DanmakuRender已成功复活。录制状态正常或者什么的，你也可以帮我想想"

【新通知效果】
  标题: DanmakuRender 状态报告
  正文:
    DanmakuRender 已成功复活。

    启动时间：2026-10-07 14:47:24
    录制服务：已启动，正在监听 32 个主播
    云端通道：CD2 正常
    近 24h 录制：7 个分段
    正在录制：暂无（当前无主播开播）

  异常时:
    标题: ⚠️ DanmakuRender 频繁重启（3次/时）
    正文里会出现 "云端通道：⚠️ CD2 服务在跑但端口未监听" 等

【各行信息来源与价值】
  启动时间            -> 系统时间
  录制服务：N 个主播   -> config.replay_config 实际数量（确认配置全部加载成功）
  云端通道：CD2 正常   -> 实时查服务状态 + 19798 端口（上传链路是否可用，
                          这是历史上最常出问题的一环）
  近 24h 录制：N 分段  -> 统计 直播回放/*（弹幕版）/*.mp4 的 mtime
  正在录制：xxx        -> 从日志读每个任务最后的 直播开始/已结束

  （最初还写了个"本地弹幕版：482 个文件"，但那含几个月历史积压，
    数字大且天天不变，没有信息量，改成"近 24h 录制"）

【关键架构改动：由 bat 发 -> 由 DMR 发】
  旧：Start_Render.bat 在启动**前**调 gen_restart_notify.py 并发通知
      -> 只能说"我要启动了"，DMR 根本没起来时也会误报"已复活"
  新：main.py 在 dmr.start() **成功后**、在后台线程里发通知
      -> 能说"已经起来了、加载了 32 个主播"，且 DMR 失败时不误报
  bat 里的 curl 逻辑已移除（避免重复通知），bat 现在只做两件事：
      切目录 + 跑 main.py --quiet（崩了就循环重来）

【频繁重启检测（含防误报）】
  FLAP_WINDOW    = 3600
  FLAP_THRESHOLD = 3
  MIN_COUNT_GAP  = 600   <- 新增：距上次计数不足 10 分钟不重复计数
  为什么加 MIN_COUNT_GAP：调试期 10 分钟内手动重启好几次会误报。
  实测验证：
      连续跑 3 次（间隔<10min） -> 总次数=1  ✅ 不误报
      把历史时间前推 11 分钟再跑 -> 总次数=2  ✅ 正确 +1
  真正的崩溃自动重启循环间隔（10 秒 + 启动）远小于 10 分钟，仍能识别。

【实现】
  tools/gen_restart_notify.py 重写为可复用模块：
      build(task_count, log_file) -> (title, content)
      send(title, content)        -> bool
      notify(...)                 -> (ok, title, content)
      单独运行 = 手动测试发送
  main.py 里新起 DMR-startup-notify 线程调用 notify()。
  通知标题/正文写成 notify_title.txt / notify_content.txt（UTF-8），
  curl 用 title@文件 / desp@文件 读取。

【为什么不用 bat 直接写中文（再次强调）】
  cmd.exe 按系统代码页(936/GBK)解析 bat，chcp 65001 还没生效就已知读完了，
  UTF-8 中文会乱码导致命令破碎、无限刷屏（2026-10-07 实际发生）。
  现在 bat 保持纯 ASCII（0 个非 ASCII 字节），中文一律走 UTF-8 文件。

【Start_Render.bat 最终内容（纯 ASCII）】
  chcp 65001 >nul
  title DanmakuRender_Guard
  :loop
  cls
  echo [%date% %time%] Starting DanmakuRender ...
  F:
  cd "F:\DanmakuRender_AutoUp"
  ".\.venv\Scripts\python.exe" main.py --quiet
  echo WARNING: program exited ... / Restarting in 10 seconds ...
  timeout /t 10
  goto loop

【验证】
  - gen_restart_notify.py 单独跑：发送成功，内容正确
  - DMR 日志确认 "[通知] 已发送: DanmakuRender 状态报告"
  - 守护 cmd PID 4776 + DMR PID 17092,9484 正常运行
  - 频繁重启防误报逻辑实测通过
